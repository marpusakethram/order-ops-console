# Order Ops Console

An order-operations console for bringing Shopify order exports, courier tracking sheets and customer complaints into a unified view.

## Project scope

- Reconcile order records across sources that do not share a common identifier.
- Support natural-language order queries.
- Surface shipment delays and return-to-origin risks.
- Use a PostgreSQL data model with backend APIs and a web interface.

## Technology stack

Python, FastAPI, Supabase (PostgreSQL), Gemini API and Vercel.

## Repository status

This repository currently contains the project overview. Application source code, setup instructions and runnable examples have not yet been added.

Customer records, credentials and private business data must not be committed to this repository.
